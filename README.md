# Songify - Modern Music Streaming Application

Songify is a sleek and responsive music streaming application built with React and Vite. It features a modern, glassmorphic user interface and provides an immersive listening experience.

## Features

- **Modern UI/UX**: Designed with a premium aesthetic using glassmorphism layout, smooth transitions, and a curated color palette.
- **Browse & Search**: Discover new artists and tracks easily with search functionality.
- **Artist Details**: View detailed artist profiles and their top tracks.
- **Favorites**: Save your favorite songs for quick access.
- **Responsive Design**: Fully optimized for desktop and mobile devices.

## Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Modern CSS (Modules/Vanilla)
- **Routing**: React Router v7
- **Linting**: ESLint

## Getting Started

1.  **Clone the repository**
    ```bash
    git clone <repository-url>
    cd songify
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run development server**
    ```bash
    npm run dev
    ```

4.  **Build for production**
    ```bash
    npm run build
    ```

## Deployment

This project is optimized for deployment on Vercel.

1.  Push your code to a GitHub repository.
2.  Import the project into Vercel.
3.  Vercel will automatically detect the Vite settings and deploy.
